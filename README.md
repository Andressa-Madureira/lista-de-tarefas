# Lista de Tarefas

Este projeto é uma aplicação simples para gerenciar tarefas utilizando HTML, CSS, e JavaScript. Ele permite criar, marcar como concluídas e remover tarefas, com persistência dos dados no navegador por meio do Local Storage.

🛠️ Tecnologias Utilizadas
<ul>
  <li>HTML: Estruturação da página</li>
  <li>JavaScript: Lógica da aplicação, manipulação do DOM e gerenciamento de tarefas</li>
</ul>

🚀 Funcionalidades

<ul>
  <li>Adicionar novas tarefas</li>
  <li>Marcar tarefas como concluídas (com estilo visual de texto riscado)</li>
  <li>Remover tarefas da lista</li>
  <li>Persistência de tarefas utilizando Local Storage</li>
</ul>

📂 Estrutura do Projeto

<ul>
  <li>HTML: Contém a estrutura básica da aplicação, como formulário e lista de tarefas</li>
  <li>JavaScript: Contém a lógica de adicionar, concluir, e remover tarefas, além da integração com o Local Storage</li>
</ul>
